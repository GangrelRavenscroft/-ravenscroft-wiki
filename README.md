# House Ravenscroft World Archive

Static wiki for the House Ravenscroft worldbuilding project.

## Archive structure

- `index.html` — archive home
- `world/` — setting-level material
- `houses/` — Great Houses, cadet Houses, and House records
- `families/` — genealogy, branches, marriages, and family navigation
- `people/` — individual Master A / Master B dossiers
- `order/` — Order governance, induction, clearance, and authority
- `places/` — estates, residences, schools, and recurring locations
- `institutions/` — companies, universities, foundations, schools, and programs
- `data/` — structured canon records
- `assets/` — canonical visual assets
- `templates/` — dossier templates
- `standards/` — authoritative construction and navigation standards

## Navigation model

Global navigation is category-based rather than person-based. Individual people are reached through the People directory, genealogy pages, and contextual links inside dossiers. Person dossiers include a section-jump navigator at both the top and bottom of the record.
